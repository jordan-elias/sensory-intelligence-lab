How it works

In "I Am Sitting in a Room," Alvin Lucier repeatedly played his voice through a speaker and microphone, recording each iteration. Over time, the room's natural resonances—determined by its dimensions and materials—became more and more prominent, while his voice gradually disappeared.

This version plays continuously by default. Each time the audio loops, it's automatically processed through the room's resonances to create the next iteration. Use the ← → buttons to navigate between iterations and hear the transformation unfold.

Choosing a room

Small room: Tight resonances around 250-1000Hz. Creates a focused, boxy character.

Bathroom: Bright reflections at 400-3000Hz. High frequencies amplified, distinctive tile acoustics.

Kitchen: Mixed surfaces, balanced resonances 300-2000Hz. Subtle transformation.

Concert hall: Large space, gentle resonances 150-2500Hz. Slow, gradual emergence.

Using the waveform editor

When you upload a file or record audio, a waveform editor appears. Drag the handles to select a region, then click "Use Selection" to crop. The zoom controls let you see fine detail. "Reset to Full" restores the original recording.

Navigating iterations

Press Play to start continuous playback. Each loop automatically creates a new iteration. Use ← → buttons to move between iterations and hear how the room's acoustic signature emerges gradually. The badge shows which iteration you're currently hearing.

Downloading your work

Export any range of iterations as a single WAV file. Select start and end iterations, choose number of loops, and download. This creates a composition showing the complete transformation from source to room resonance.

Try it in a real room

The physical version: record yourself speaking. Play it back through a speaker in a room and record it with a microphone placed elsewhere in the same room. Play that recording back and record again. Repeat 8-10 times to hear the room's resonances emerge.
